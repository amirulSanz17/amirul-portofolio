
# DESIGN.md — Personal Portfolio

## 1. Design Identity

Design direction: Dark Professional.

The website represents an Information Systems student
focused on Business Analysis, Data Analysis,
System Development, and Technology.

The visual identity should communicate:
- Technical competence
- Professionalism
- Analytical thinking
- Clarity
- Authenticity

Avoid generic AI-generated aesthetics.

## 2. Visual Direction

Use a sophisticated dark interface with:
- Deep charcoal backgrounds
- Subtle surface separation
- Restrained accent colors
- Strong typographic hierarchy
- Intentional whitespace
- Editorial-inspired layouts
- Precise alignment and spacing

Do not make every section look like a dashboard.

## 3. Color System

Background: #090B0E
Surface: #11151B
Elevated Surface: #1D242D
Primary Text: #E8EDF2
Secondary Text: #8B98A8
Border: #28313B
Accent: #7DD3A7

Accent colors should be used selectively.

## 4. Typography

Use a clear typography hierarchy.

Headings:
- Strong visual presence
- Controlled line lengths
- Responsive font sizing

Body:
- Highly readable
- Comfortable line height
- Clear contrast

Avoid excessive uppercase labels and unnecessary
letter spacing.

## 5. Layout Principles

- Use structured grids.
- Maintain consistent alignment.
- Use whitespace intentionally.
- Avoid repetitive card layouts.
- Use different compositions where appropriate.
- Prioritize content hierarchy over decoration.

## 6. Components

Navbar:
Minimal, functional, and clearly structured.

Hero:
Strong personal positioning and clear introduction.

About:
Readable editorial layout.

Projects:
Focus on project context, contribution,
technical implementation, and outcomes.

Experience:
Clear chronology and meaningful descriptions.

Skills:
Organized by capability and technical category.

Contact:
Simple and accessible.

## 7. Interaction

- Subtle hover feedback.
- Purposeful transitions.
- Accessible focus states.
- No unnecessary animations.
- Respect prefers-reduced-motion.

## 8. Responsive Design

Support:
- Mobile
- Tablet
- Desktop

Ensure proper text wrapping, spacing,
navigation, and layout reflow.

## 9. Anti-Patterns

Avoid:
- Excessive gradients
- Glassmorphism everywhere
- Unnecessary glowing effects
- Identical cards across sections
- Decorative elements without purpose
- Generic marketing copy
- Fake statistics
- Random animations
- Excessive rounded corners
- Unnecessary dependencies

## 10. Engineering Constraints

Preserve the existing:
- React architecture
- Vite configuration
- TypeScript
- Tailwind CSS 4    
- Supabase integration

Do not remove existing features.

Prioritize maintainability, accessibility,
performance, and functional correctness.
